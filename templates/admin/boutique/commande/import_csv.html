Importer des commandes depuis un fichier CSV

Instructions

Cette fonctionnalité permet d'importer des commandes depuis un fichier CSV.

Format requis :

  • Séparateur : Point-virgule (;)
  • Encodage : UTF-8
  • Colonnes obligatoires :
    • Numero_Commande
    • Client_Username
    • Total_Commande
  • Colonnes optionnelles :
    • Statut
    • Adresse_Livraison
    • Telephone
    • Notes

Méthodes d'import disponibles

1. Via le Dashboard (recommandé)

Aller au Dashboard

Le dashboard offre une interface complète avec gestion des erreurs et feedback en temps réel.

2. Via l'API directement

Endpoint : POST /api/commandes/import/csv/
Paramètre : csv_file (fichier)
